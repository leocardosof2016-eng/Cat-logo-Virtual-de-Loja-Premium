Ia Strix do Github

Aja como um Desenvolvedor Front-end Sênior especialista em UI/UX Mobile e E-commerce. Preciso que você crie um arquivo único (Single Page Application) contendo HTML, CSS e JavaScript para um "Catálogo Digital de Eletrônicos Premium" chamado **TechVision Store**.
O código deve ser totalmente funcional, responsivo e esteticamente premium. Siga estritamente as especificações abaixo:
### 1. Stack Tecnológica
- **Estrutura:** HTML5.
- **Estilização:** Tailwind CSS (via CDN) + Estilos customizados internos (`<style>`).
- **Ícones:** FontAwesome 6 (via CDN).
- **Fontes:** Google Fonts ('Plus Jakarta Sans' ou 'Inter').
- **Lógica:** Vanilla JavaScript (sem frameworks como React/Vue).
### 2. Identidade Visual (Design System)
- **Tema:** Dark Mode Futurista/Premium.
- **Cores Principais:** Fundo Escuro (`#0F172A` a `#1E293B`), Detalhes em Azul Neon (`#3B82F6`) ou Roxo Elétrico (`#8B5CF6`) para dar ar tecnológico, Texto claro (`#F1F5F9`).
- **Efeitos:** Use `backdrop-blur` (efeito de vidro) nos modais e header. Bordas sutis brilhantes.
- **Elementos:** Cards com design limpo, botões com hover suave, inputs modernos.
### 3. Estrutura da Página
- **Header:** Imagem de fundo (cover tech/setup) com overlay escuro, título "TechVision Store", badge de status "Enviando para todo Brasil" (com bolinha pulsando) e botão de busca.
- **Navegação:** Barra de categorias (Todos, Smartphones, Notebooks, Áudio, Gamers, Acessórios) com rolagem horizontal (sticky no topo). Ícones tecnológicos para cada categoria.
- **Lista de Produtos:** Cards com imagem do produto, título, "A partir de R$..." e botão de ver detalhes.
### 4. Funcionalidades (JavaScript)
- **Busca:** Um modal de busca em tela cheia que filtra os produtos por nome ou especificações.
- **Modal de Produto (Vitrine):** Ao clicar no item, abre um modal (slide-up) mostrando:
  - Foto grande do produto.
  - Descrição técnica detalhada (Processador, Memória, etc.).
  - **Opcionais/Upsell:** Checkboxes para adicionar serviços ou acessórios (ex: "Garantia Estendida +1 Ano (+R$ 150,00)", "Película de Vidro (+R$ 30,00)", "Cabo Extra (+R$ 50,00)"). A soma deve atualizar o preço total dinamicamente.
  - Campo de observação (Ex: "Prefiro na cor preta se tiver").
  - Seletor de quantidade (- 1 +).
  - Botão "Adicionar ao Carrinho" com o preço final calculado.
- **Carrinho de Compras:**
  - Uma barra flutuante "Minha Sacola" aparece no rodapé apenas quando há itens.
  - **Botão WhatsApp Flutuante:** Fixo no canto inferior direito. Deve subir ligeiramente para não ficar atrás da barra do carrinho quando ela aparecer.
- **Checkout (Modal Final):**
  - Lista de itens escolhidos.
  - **Cupom de Desconto:** Campo para inserir cupom. Se digitar "TECH10", aplica 10% de desconto.
  - Campos para Nome, Endereço de Entrega e Forma de Pagamento.
  - Resumo financeiro (Subtotal, Desconto, Total).
  - Botão "Finalizar no WhatsApp": Monta uma mensagem formatada com a lista de produtos, opcionais selecionados e total, abrindo a API do WhatsApp.
### 5. Dados (Hardcoded)
Crie um array de objetos `CATALOG_ITEMS` com pelo menos 8 itens de tecnologia variados (iPhone 15, MacBook Air, Fone Sony Noise Cancelling, Mouse Gamer, Teclado Mecânico, etc.), usando imagens do Unsplash relacionadas a tecnologia. Alguns itens devem ter o array de `extras` (serviços ou acessórios).
### 6. Detalhes de CSS Importantes
- Remova a scrollbar padrão (`no-scrollbar`).
- Crie animações suaves de `pulse` para o botão do WhatsApp.
- Checkboxes devem ser customizados (estilo tech, borda colorida quando marcados).
Gere o código completo em um único bloco HTML.
